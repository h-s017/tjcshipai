核對日期：2026-10-18（台灣時間）。範圍：2021-09 至 2026-10，共 62 個月。

公開 feed 實際取得與 sitemap 逐網址核對均為 **1,867 篇**。原 131 篇，新增 **1,736 篇**，已發現網址缺漏 **0**、下載失敗 **0**、既有文章遺失 **0**。如鷹展翅原有 **1,092 篇逐欄保留**，合計 **2,959 篇**。

## 失敗原因與修復

Actions run 39048603309 顯示 sitemap_count=0、indexed_count=131。月份 regex 中 `20\\d` 多跳脫一層，所有有效文章被排除；不是零篇歷史文章。build_bible_index.py 另含字面的 `\n`，已修復。

公開來源：Blogger `/feeds/posts/summary?alt=json`、`/sitemap.xml` 及其 3 個子 sitemap。起始批次 100；異常時降至 50、25、12、10，重試 4 次，節流，按請求網址快取 metadata checkpoint。深分頁止於 1,850 篇，日期窗口重疊去重再取回 17 篇，最後與 sitemap 1,867 URL 完全一致。只保存標題、永久網址、發布日期與來源，不保存文章內文。

## 重現與驗證

Python 3.12+、Node 22+，不需額外套件。從 repository 根目錄執行：

```sh
python scripts/audit_shipai_months.py  # 只產生稽核報告，不覆寫索引
python scripts/test_blogger_archive.py
node scripts/check_bible.cjs
python scripts/build_bible_index.py  # 完整核驗及章節測試通過後原子更新
```

快取位於 `.cache/blogger`，中斷後用相同命令續跑。新稽核請設定 `BLOGGER_CACHE_DIR` 為全新目錄，避免混用不同日期的快照。CI 每次乾淨 checkout；稽核 workflow 僅上傳 artifact，不直接提交主站。後續執行的 added 以執行當下既有索引為基準，因此補齊後重跑應為 0。

自動測試涵蓋原文章逐欄保留、URL 去重、網路失敗與集合不一致時禁止覆寫、快取重跑一致性；前端直接執行 bible.html 的實際 JS，驗證中文/阿拉伯/逐位數字、廿卅、括號、耶ㄧ、啓，以及「約一」與「約一 第一章」；以實際兩來源同章資料檢查 renderMatches 產出的來源標題及連結。此為 DOM 模擬測試，未進行視覺截圖測試。
