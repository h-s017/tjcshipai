# 每日讀經心得｜教會同工安裝說明

## Android（目前測試版）

1. 開啟 https://github.com/h-s017/tjcshipai/actions/runs/40115318471
2. 在 Artifacts 區下載 `daily-bible-android-debug-apk` ZIP（可能需要 GitHub 登入）。
3. 解壓縮後取得 `app-debug.apk`，於 Android 手機開啟並依系統提示安裝。
4. 僅從教會確認的來源取得檔案；勿安裝陌生人轉傳或來源不明的 APK。
5. 開啟「每日讀經心得」即可免登入閱讀，使用 App 上方的「分享」傳送章節連結。

注意：此檔案為已通過六項實機功能測試的 Debug APK，供同工小範圍試用，不適合作為長期正式發佈版本。GitHub Artifact 將到期；且不同 Debug 簽署金鑰產出的 APK 可能無法覆蓋安裝更新。

## iPhone（免費 PWA）

1. 在 Safari 開啟 https://h-s017.github.io/tjcshipai/bible.html
2. 點選 Safari 分享圖示，選擇「加入主畫面」。
3. 在主畫面點選「每日讀經」圖示開啟。

不需要 Apple Developer 付費帳號，也不需要讀者登入。iPhone 目前並非原生 IPA App。

## 問題回報

請提供手機品牌與 Android/iOS 版本、操作步驟及錯誤畫面；請勿提供私人密碼或帳號憑證。
